# Funmite POS — Cashier Quick Guide

## Login

1. Launch FunmitePOS.exe
2. Enter your username and password
3. Click Login
4. You will see the POS screen (this is your only screen)

## Making a Sale

### Step 1: Add Products
- **Scan a barcode** — point the scanner at the product barcode
- **Search by name** — type in the search box and select from results

### Step 2: Adjust Cart
- Change quantity using the spinner (+ / -)
- Remove an item by clicking the remove button

### Step 3: Select Customer
- Select an existing customer from the dropdown
- Or click "New Customer" to add a walk-in customer (name required, phone optional)

### Step 4: Payment
- Select **Bank POS** or **Bank Transfer**
- Enter the payment reference number
- Click **COMPLETE SALE**

### Step 5: Receipt
- Receipt prints automatically (if printer is connected)
- The sale is complete

## What You Can Do

| Feature | Access |
|---------|--------|
| Make sales | Yes |
| Scan barcodes | Yes |
| Add walk-in customers | Yes |
| View your own sales | Yes |
| Print receipts | Yes |

## What You Cannot Do

| Feature | Access |
|---------|--------|
| Apply discounts | No (Admin only) |
| Exchange items | No (Admin only) |
| Add/edit products | No (Admin only) |
| Manage inventory | No (Admin only) |
| View profit reports | No (Admin only) |
| Create backups | No (Admin only) |
| Access Settings | No (Admin only) |

## Offline Mode

If the internet is disconnected:
- You can still make sales normally
- The status bar shows "Offline"
- Sales are saved locally and will sync when internet returns
- Do NOT worry — your sales are safe

## Tips

- The barcode scan field is automatically focused — just scan
- If a product is not found, the barcode is not in the system (tell the Admin)
- If stock is insufficient, the sale cannot complete (tell the Admin)
- After a sale, check if a low-stock warning appears
- Receipt numbers follow the format: FUN-YYYYMMDD-NNN

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Barcode not found | Product may not be in the system — tell the Admin |
| Insufficient stock | Product quantity is too low — tell the Admin |
| Printer not working | Sale still completes — receipt can be reprinted by Admin |
| App won't close | Use Task Manager (Ctrl+Alt+Del) |
