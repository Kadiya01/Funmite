# Funmite POS — Troubleshooting Guide

## Application Won't Start

**Symptom:** Double-clicking FunmitePOS.exe does nothing or shows an error.

**Cause:** Missing Visual C++ runtime, antivirus blocking, or corrupted files.

**Check:**
1. Check if `FunmitePOS.exe` exists in the folder
2. Check Windows Event Viewer for application errors
3. Temporarily disable antivirus and try again

**Solution:**
1. Install Microsoft Visual C++ Redistributable (latest x64 version)
2. Run as Administrator (right-click > Run as administrator)
3. Re-download the application if files are corrupted

**Escalation:** If the issue persists, check `logs/funmite.log` for error details.

---

## Login Failure

**Symptom:** "Invalid username or password" error with correct credentials.

**Cause:** Wrong password, disabled account, or database corruption.

**Check:**
1. Verify username spelling (case-sensitive)
2. Verify password (check Caps Lock)
3. Check if the account exists in the database

**Solution:**
1. Reset password via another Admin account
2. If no Admin is available, delete `data/funmite.db` and restart (loses all data)
3. Check `logs/funmite.log` for authentication errors

**Escalation:** If the database is corrupted, restore from a backup.

---

## Barcode Scanner Not Working

**Symptom:** Scanning a barcode does not add the product to the cart.

**Cause:** Scanner not in HID mode, wrong barcode format, or product not in database.

**Check:**
1. Test scanner in Notepad — scanning should type characters
2. Verify the barcode format (13 digits for products)
3. Check if the product exists in the Products screen

**Solution:**
1. Ensure scanner is in keyboard (HID) mode — refer to scanner manual
2. Reset scanner to factory defaults if needed
3. Add the product to the database first

**Escalation:** If the scanner works in Notepad but not in the app, check `logs/funmite.log`.

---

## Product Barcode Not Found

**Symptom:** Scanning a barcode shows "Product not found."

**Cause:** Product not in database or wrong barcode.

**Check:**
1. Open Products screen and search for the product
2. Verify the barcode matches what's printed on the product
3. Check if the product is active (not deactivated)

**Solution:**
1. Add the product to the database with the correct barcode
2. Reactivate the product if it was deactivated
3. Print a new barcode label if the old one is damaged

**Escalation:** If the barcode was generated by the system but doesn't work, report the issue.

---

## Thermal Printer Not Printing

**Symptom:** Receipt does not print after completing a sale.

**Cause:** Printer offline, driver issue, paper jam, or wrong port.

**Check:**
1. Check if the printer is powered on
2. Check Windows Devices and Printers — is the printer listed?
3. Check for paper jam
4. Print a test page from Windows

**Solution:**
1. Power cycle the printer
2. Reinstall the printer driver
3. Check the printer is set as default in Windows
4. Verify the cable connection

**Escalation:** The sale is saved even if printing fails — receipts can be reprinted by Admin.

---

## Database Problem

**Symptom:** Application shows errors, data is missing, or operations fail.

**Cause:** Database corruption, disk full, or migration failure.

**Check:**
1. Check available disk space
2. Check `logs/funmite.log` for database errors
3. Verify `data/funmite.db` exists

**Solution:**
1. Free disk space if low
2. Restore from a backup (Settings > Restore)
3. If no backup, delete `data/funmite.db` and restart (loses all data)

**Escalation:** If restoring from backup fails, contact support.

---

## Backup Failure

**Symptom:** Creating a backup fails or produces an invalid file.

**Cause:** Disk full, permission issue, or database locked.

**Check:**
1. Check available disk space in the backups directory
2. Check file permissions
3. Check if another process has the database locked

**Solution:**
1. Free disk space
2. Run the application as Administrator
3. Close other applications that might lock the database

**Escalation:** If the issue persists, check `logs/funmite.log` for backup errors.

---

## Restore Failure

**Symptom:** Restoring a backup fails or corrupts the database.

**Cause:** Invalid backup file, disk full, or database locked.

**Check:**
1. Verify the backup file is valid (Settings > Backup > check file size)
2. Check available disk space
3. Close other applications

**Solution:**
1. Try a different backup file
2. The pre-restore safety backup is always created — check `backups/` for `pre_restore_*` files
3. If the live database is corrupted, use the pre-restore backup

**Escalation:** If both the live database and pre-restore backup are corrupted, contact support.

---

## Internet Unavailable

**Symptom:** Cloud sync shows "Offline" or "Failed."

**Cause:** Network cable disconnected, WiFi off, or internet outage.

**Check:**
1. Check if other applications can access the internet
2. Check network cable / WiFi connection
3. Try opening a website in a browser

**Solution:**
1. Reconnect network cable or enable WiFi
2. Wait for internet to be restored
3. The application continues working offline — sales are queued for sync

**Escalation:** If the internet is down for an extended period, the application continues to work. Sync resumes automatically when connectivity returns.

---

## Cloud Sync Unavailable

**Symptom:** Sync status shows "Failed" or "Error."

**Cause:** Cloud database URL is wrong, credentials expired, or server down.

**Check:**
1. Verify the cloud URL in Settings > Cloud Sync
2. Check if the cloud database is accessible from a browser
3. Check device registration status

**Solution:**
1. Re-register the device (Settings > Cloud Sync > Register)
2. Verify the cloud URL is correct
3. Wait for the server to be available

**Escalation:** If the cloud server is down, the application continues working offline. Contact the server administrator.

---

## Pending Sync Not Clearing

**Symptom:** Sync status shows pending count that doesn't decrease.

**Cause:** Network issue, server error, or conflict.

**Check:**
1. Check internet connectivity
2. Check sync status in Settings > Cloud Sync
3. Click "Sync Now" to trigger manual sync

**Solution:**
1. Wait for automatic retry (30s push / 60s pull intervals)
2. Check `logs/funmite.log` for sync errors
3. Restart the application

**Escalation:** If pending count remains high after multiple retries, check the cloud server logs.

---

## Device Registration Failure

**Symptom:** Clicking "Register" in Settings shows an error.

**Cause:** Cloud URL is wrong, network issue, or server rejection.

**Check:**
1. Verify the cloud URL is correct
2. Check internet connectivity
3. Check if the cloud server is running

**Solution:**
1. Re-enter the cloud URL
2. Check network connection
3. Contact the server administrator

**Escalation:** The application works offline without registration. Sync is not available until registration succeeds.

---

## Cloud Authentication Failure

**Symptom:** Sync operations fail with authentication errors.

**Cause:** API key expired, device not registered, or server issue.

**Check:**
1. Check if `data/sync_credentials.json` exists
2. Verify the device is registered on the cloud server
3. Check if the API key is valid

**Solution:**
1. Re-register the device (Settings > Cloud Sync > Register)
2. Delete `data/sync_credentials.json` and re-register
3. Contact the server administrator

**Escalation:** The application works offline without authentication. Sync resumes when credentials are valid.
